# GRIDIT

**GRID + IT** — computerkorea MD팀 상품관리 AI 에이전트

상품 데이터를 입력하면 DB 정합성 점검부터 판매·재고 분석, 시장 트렌드, 전략 제안까지 한 번에 확인할 수 있는 MD 업무용 대시보드입니다.

🔗 **라이브 데모**: https://romi4670.github.io/gridit/

---

## 배경 및 목적

computerkorea에서 상품관리·AS등록관리·상품DB관리·상품등록 업무를 담당하는 MD가, 흩어져 있는 상품 데이터를 한 곳에서 점검하고 다음 액션을 판단할 수 있도록 만든 실습 아티팩트입니다. 표 하나만 봐서는 놓치기 쉬운 신호를 짚어주는 것이 핵심 목표입니다.

## 핵심 기능 (7단계 워크플로우)

1. **데이터 입력** — 상품명, 키워드, 카테고리, 공급사, 등록월, 원가, 판매가, 재고, 월판매량, AS건수, 경쟁사가 입력 (샘플 데이터 자동 채우기 지원)
2. **상품DB 정합성** — 필수 필드 누락·중복 상품명·마진 이상·재고 불일치 진단 + 카테고리별 표준 키워드 슬롯 기준 상품명·키워드 정정 제안
3. **판매·매출 연동** — 상품별 추정 월매출(판매가 × 월판매량), 등록만 되고 안 팔리는 상품 파악
4. **재고·회전율** — 재고 소진 예상일 계산(재고수량 ÷ 월판매량 × 30일), 발주 타이밍 제안
5. **AI MD 전략** — 상품명·키워드·카테고리만으로 계산되는 시장·키워드 트렌드 + 경쟁사·시장가 비교 + 가격·재고·판매 데이터 기반 전략 액션 제안(클릭 시 상세 확장, 리포트 다운로드 가능)
6. **마케팅 매거진** — 계산된 진단·전략 신호와는 별도로 분리된 참고자료 탭. 마케팅·AI·업무 용어사전(142개, xlsx 다운로드), [요즘 마케팅] 트렌드·이슈 코너, B2C/B2B 마케팅 전략(홈페이지·SNS)으로 구성
7. **대시보드** — 전체 상품군 현황(등록 상품 수, 추정 월매출 합계, DB 정합성 이슈, 리스크 상품) 요약

## 카테고리별 키워드 슬롯 표준

상품명·키워드 정합성 진단과 정정 제안의 기준이 되는 슬롯 규격입니다.

| 카테고리 | 슬롯 구성 | 슬롯 수 |
|---|---|---|
| CPU | 코드네임 · 모델번호 · 영문모델명 · 용도어 · 옵션(저가형/벌크/병행수입/정품/쿨러/중고 중 택1) | 5개 |
| 메모리 | 제조사 · DDR타입 · 용량 · 속도(MHz)/CL · 용도(데스크탑용/노트북용/서버용) · 특성(선택, 최대 2개) | 5~7개 |
| 그 외 (모니터/VGA/메인보드/파워/쿨러/주변기기 등) | 모델명/제조사 · 핵심스펙 · 용도 · 옵션(선택) | 3~5개 |

## 기술 스택

- 순수 HTML/CSS/JavaScript 단일 파일, 별도 프레임워크·백엔드 없음
- 모든 계산은 브라우저에서 클라이언트 사이드로 처리
- 디자인: 잉크 네이비 + 비비드 오렌지 강조색, IBM Plex Sans/Mono 기반 데이터 콘솔 톤

## 사용 방법

- **바로 써보기**: [라이브 데모](https://romi4670.github.io/gridit/) 접속 후 "샘플 데이터 채우기" 클릭
- **로컬 실행**: `index.html`을 다운로드해 브라우저로 열면 그대로 동작합니다.

## 주의사항

- 현재 버전은 데이터를 브라우저 메모리에만 보관합니다. **새로고침하면 입력한 데이터가 초기화**되므로, 실사용 시에는 별도 저장 연동이 필요합니다.
- 카테고리는 상품 추가 시 드롭다운에서 **직접 선택**해야 합니다(자동 판별 아님). 선택하지 않으면 등록이 되지 않도록 막아뒀습니다.
- 예시로 표시되는 가격·재고·매출 수치는 실데이터가 아닌 샘플 데이터입니다.
- 상품명·키워드 정정 제안은 참고용이며, 최종 반영 여부는 담당자가 판단합니다.

## 관련 프로젝트

GRIDIT의 상품명·키워드 검증 규칙은 별도로 운영 중인 CNO(상품명검증기) 프로젝트의 규격을 기반으로 합니다. P.Ops(상세DB 정리), CQO(상품 DB 품질검수) 등도 같은 맥락에서 이어지는 프로젝트입니다.
